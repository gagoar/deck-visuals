deck-visuals

Decides where a visual belongs and which kind. Never renders the deck.

A guidance-and-injection layer for HTML decks: inline-SVG concept diagrams, dataviz-backed charts with a validated brand palette, icon anchors, and GIF levity — each a self-contained fragment you inject into a deck frontend-slides already built.

What it does

Three pillars

Impactful visuals
Inline-SVG concept diagrams for relationships and flows. Icon anchors for single ideas. Hero-moment illustrations are deferred, not faked.
Data-viz principles
Chart form and marks come from the built-in dataviz skill. Color comes from a validated brand palette. Every chart ships a reachable table twin.
Levity
Real GIFs by direct media URL, at a deliberate cadence, with alt text and a reduced-motion still on every one.
Division of labor

Layer boundaries

frontend-slides — renders shell, stage, theme
deck-visuals — guides + injects one fragment
iceberg — copy only, never the finished .html

Fragments are renderer-agnostic. Each carries its own scoped <style> and assumes nothing about the host page's classes or globals. Injecting one never edits the shell around it.

How it works

The pipeline

  • 1Copy. Draft slide text. Run iceberg on the prose only. iceberg
  • 2Render. Build or open the deck. frontend-slides
  • 3Chart injection. dataviz form/marks + brand palette color, inline-SVG + table twin. deck-visuals
  • 4Concept-visual injection. Diagram, icon, or a deferred placeholder — by the decision rule. deck-visuals
  • 5Levity injection. GIF fragments at a tasteful cadence. deck-visuals
  • 6Deliver. Ship to the notes site. deliver-doc
Validated, not eyeballed

Brand palette

Dark mode: PASS

Eight categorical slots, anchored on the deck accent #3ea6ff family, checked with the built-in dataviz skill's colorblind-safety validator — the authority for these numbers — rather than by eye. Worst adjacent color-vision-deficiency ΔE against the dark surface: 8.4, clearing the 8.0 target; worst adjacent normal-vision ΔE: 19.3, clearing the 15.0 floor. This is a dark-only set: the decks this plugin targets are dark-only today, and a light-mode palette is a separate, not-yet-derived selection. See skills/deck-visuals/assets/brand-palette.md for the full validator output.

Getting started

Install

# Install
/plugin marketplace add gagoar/gago-plugins
/plugin install deck-visuals@gago-plugins
/reload-plugins
Ask in natural language once a deck exists — "add visuals to my deck," "chart this," "add a levity slide." The skill reads the deck and returns fragments to inject; it never rewrites the shell.
What ships

Fragments
