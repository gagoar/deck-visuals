How it works

The pipeline.

Six steps. The ones tagged deck-visuals are the plugin's own; the rest hand off to the skills that already do them well.

Read the pipeline →
  1. Onboard (out-of-band). A local swipe picker rebuilds the presenter's pop-culture profile. deck-visuals
  2. Copy. Draft slide text. Run iceberg on the prose only. iceberg
  3. Render. Build or open the deck. frontend-slides
  4. Chart injection. dataviz form/marks + brand palette color, inline-SVG + table twin. deck-visuals
  5. Concept-visual injection. Diagram, icon, or a deferred placeholder — by the decision rule. deck-visuals
  6. Levity injection. GIF fragments at a tasteful cadence. deck-visuals
05

Validated, not eyeballed

The rigor is real.

  • The palette validator (dv-tools) is a real Go binary doing the colorblind-safety math — not eyeballed.
  • Every chart ships with a reachable table-view twin.
  • Every GIF is verified by a direct-URL check before it ships — never a guessed link.
  • The local pickers are zero-runtime binaries: bind 127.0.0.1 only, no auth, no outbound calls. Nothing leaves the machine.

06

It knows what you'd reference

Matches the shows you love.

Swipe through 50 shows and mark what you recognize — recognizing one means you'd get the jokes built around it. What you recognize unlocks accent themes matched to it: house default, a pinned Wes Anderson theme, and 14 more matched to shows like The Matrix, Breaking Bad, and Star Wars. Each theme carries its own coordinated dark surface, hue-matched to the accent — a warm theme never sits on a cold navy floor. It never asks you to name a color — you pick from swatches.
