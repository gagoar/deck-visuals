THE STANDARD

Three layers.
One question each.

Launch requires GALAXY, always. Add one PACKAGE for the main delivery. Add SHIP only where the hull is weird.
L1 GALAXY

How do the planets connect, where does the route break, how far is Omicron Persei 8, roughly what does fuel cost?

1 star map + 3 small tables
L2 SHIP

What runs inside one spaceship, and how is it laid out?

1 deck plan + 1 crew table, per non-trivial ship
L3 PACKAGE

For this delivery, what happens step by step, and what's the contract?

1 sequence diagram per delivery + a waiver link

Each layer produces one Sketch — a Galaxy Sketch, a Ship Sketch, or a Package Sketch.
