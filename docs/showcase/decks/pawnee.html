v2.4.0 moves through every checkpoint its department defines, the same candidate each time. What's different is the venue: permits, crowd size, weather — set per park, not per candidate (and nobody gets a waffle without a form).

Opening is the mechanical action: placing a swing set into a park. When that reaches the citizens — staged through a soft launch, once the pit is filled — it is a grand opening. Same event, named from the citizens' side.
