# Meme library — the always-on levity fallback

This file is **config, not documentation**. It is the pool `references/levity.md`
reaches for when no familiar source fits a claim and reaction mode still needs a
widely-legible image. Unlike `assets/show-catalog.md`, nothing here is surveyed or
gated by recognition — these are broadly-known internet references chosen because
they land without a shared back-catalog.

**Store search terms, not URLs.** Same rule as the rest of levity: the direct media
URL is sourced and verified at use (`WebSearch` → resolve → `dv-tools check-media-url`),
never pinned here, so the library never link-rots. Keep it to references that have
stayed legible for a few years — a hyper-current meme dates a deck the moment the
trend passes, and an external audience often hasn't seen it.

## Format

Grouped by `##` heading. Each entry:

- `**Name**` — the meme as people know it.
- `Shape/beat:` — the concept shape (matching `levity.md`'s vocabulary where it
  fits) or the reaction beat it carries.
- `Search:` — the query for sourcing the direct media URL.
- `Travels externally:` — `yes` / `limited` / `no` and a one-line reason. Drop
  `limited`/`no` entries for external decks, same gate as `familiar-sources.md`.
