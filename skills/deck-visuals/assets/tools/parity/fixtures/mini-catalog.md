# Mini show catalog (parity fixture)

Small, synthetic stand-in for `assets/show-catalog.md`, paired with
`mini-levity.md`. Built so that, at the default `--target 3`, every shape in
the mini seed library is a GAP (each has only 2 carriers), and one catalog
`Shapes:` tag ("Not A Real Shape") has no match in the mini seed library —
that mismatch is the Drift case.
